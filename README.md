## 💡 학습 소감

Data Engineering Zoomcamp를 통해 데이터 파이프라인의 전체 흐름을 직접 구축하며 학습했습니다.
단순히 도구를 사용하는 것에 그치지 않고, **각 기술을 선택한 이유와 트레이드오프**를 이해하는 데 집중했습니다.
MES 개발자로 3년간 제조 현장 데이터를 다룬 경험을 바탕으로, 실제 산업 환경에 적용 가능한 데이터 엔지니어링 역량을 키우고 있습니다.
